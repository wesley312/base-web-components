<duration-input>

A custom input element that edits an ISO 8601 duration (PnYnMnDTnHnMnS) through separate numeric fields.

Input Attributes

There are few attributes you may set:

  • value: Same as value attribute in <input>.
  • legend: Set the content of legend, default to Duration, only text is supported.

Current value:

Input Validation

Only required attribute is supported for validation. Other than that, any positive integer can be inputted besides second where any positive decimal number is accepted. checkValidity() and reportValidity() methods from HTMLFormElement interface are supported.

Localization (i18n)

Field labels come from Intl.NumberFormat's own unit translations, not a hardcoded dictionary, set lang and they follow. Use the labels attribute only for manual overrides (abbreviations, a locale Intl doesn't cover well, etc). 

<!-- labels derived automatically from lang -->
<duration-input lang="fr" legend="Se répète tous les"></duration-input>
<!-- overrides default labels with custom labels -->
<duration-input legend="Custom short labels"
  labels='{"year":"yr","month":"mo","week":"wk","day":"d","hour":"h","minute":"m","second":"s"}'
></duration-input>

Inherited from a parent (no lang on the element itself)

<div lang="de"> ← locale lives here, not on <duration-input> 

<!-- also inherits from an ancestor's lang, e.g. <html lang="de"> or any wrapper -->
<div lang="de">
  <duration-input legend="Wiederholt sich alle"></duration-input>
</div>
 
<script>
  // also settable as properties
  el.lang = 'de';
</script>

Text direction (RTL)

No dir needed — direction is inferred from the locale and the whole field mirrors automatically.

An explicit dir (on the element or an ancestor) always wins over the inferred one: 

<!-- direction auto-inferred as rtl from lang="ar" -- no dir attribute needed -->
<duration-input lang="ar" legend="يتكرر كل"></duration-input>
 
<!-- explicit dir always overrides the inferred one -->
<duration-input lang="ar" dir="ltr" legend="forced ltr"></duration-input>

Styling

part name

Elements are exposed for styling using part names. You can find the part names by hoverover each element below.

Duration

Styling using ::part()

<style>
  /* ::part() — reach into specific shadow elements */
  duration-input::part(fieldset) {
    border: 2px dashed orange;
    border-radius: 4px;
  }
  duration-input::part(legend) {
    text-transform: uppercase;
    letter-spacing: 0.05em;
    font-size: 0.75rem;
  }
  /* target all fields */
  duration-input::part(input) {
    border-radius: 999px;
    text-align: center;
  }
  /* target a single field */
  duration-input::part(input-second) {
    border-color: orange;
  }
</style>
